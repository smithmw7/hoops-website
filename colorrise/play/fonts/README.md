# Montserrat

Local webfonts converted losslessly from the user's installed Montserrat version 8.000 TrueType files. The game and dashboard load only these WOFF2 files through `fonts.css`; no installed font or network font service is required.

- 200 ExtraLight, 300 Light, 400 Regular, 500 Medium
- 600 SemiBold, 700 Bold, 800 ExtraBold, 900 Black
- The supplied `Logo.psd` uses Montserrat Regular for COLOR and Montserrat Bold for RISE.
- Redistribution license: `OFL.txt`. Copyright notice matches the bundled font metadata.

The font outlines, naming and weight metadata are unchanged. CSS uses the single family name Montserrat; synthetic styles are disabled in the game.
